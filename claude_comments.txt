**1. Silent empty output when `--use-external-engines` is used**

`_parse_with_external()` in both `AdvancedASAConfig` and `AdvancedFTGConfig` is a bare `pass`. This means `--use-external-engines` will successfully instantiate the object but return no network objects, no ACLs, and no rules—producing silently empty/wrong results for the user. This is worse than an error.

Suggested fix: add an explicit `NotImplementedError` or a warning so users know this is non-functional scaffolding:

```python
def _parse_with_external(self):
    raise NotImplementedError(
        "Advanced engine is not yet implemented. Remove --use-external-engines."
    )
```

```python
try: result = {ipaddress.ip_network('::/0')}
except: result = set()
...
try: result = {to_ip_network(token)}
except: result = set()
```

Bare `except:` catches `SystemExit`, `KeyboardInterrupt`, etc. Use `except ValueError:` or `except (ValueError, TypeError):` here. This is copy-pasted from the legacy parser and the same issue should be fixed there too.

**3. `fortios_xutils` imported but immediately discarded**

In `AdvancedFTGConfig.__init__`:
```python
import fortios_xutils  # ← assigned to nothing, never used
```

The guard works, but the import is discarded immediately. This is fragile—if the library is partially importable this check would pass while actual usage later fails. Use:
```python
try:
    import fortios_xutils as _fortios_xutils  # noqa: F401
except ImportError:
    raise ImportError(...)
```

**4. Fixture paths in tests are likely wrong**

`tests/test_external_engines.py` lines 690–697 reference `"configs/fixtures/asa-path-sample.conf"` and `"configs/fixtures/forti-path-sample.conf"`. CLAUDE.md puts fixtures under `tests/fixtures/`. The project's CLAUDE.md explicitly states: _"Prefer verbose docstrings for parser internals to aid future refactors."_

The PR removes the complete `Args:` and `Returns:` sections from `compare_old_new` in `parsers/cisco/asa/inspect.py` and strips the `Returns:` block from `path_check` in `parsers/cisco/asa/path.py`.
